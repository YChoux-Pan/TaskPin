# Snipaste 逆向报告 & TaskPin 功能矩阵

> 目标：在不复制任何资产/代码的前提下，**按可观察行为与公开文档**重建一个功能对标的本地软件 TaskPin。
> 方法：静态资源提取（Qt 翻译表）+ 官方 CLI 文档 + 运行时观察。证据可复现，见 §1。

---

## 1. 逆向方法与证据

| 手段 | 产出 | 证据文件 |
|---|---|---|
| 安装包结构清点 | 技术栈与依赖清单 | 本文 §2 |
| Qt 翻译表提取（`lang/zh_cn.qm`） | **2738 条真实 UI 文案**，覆盖每个菜单项/对话框/提示 | `docs/reverse/snipaste-ui-zh.txt` |
| 自研 `.qm` 提取器 | 可复用于版本对比（后续升级可 diff 功能面） | `tools/QmExtract/` |
| ASCII 字符串提取 | CLI 参数、内部键名 | `docs/reverse/snipaste-ascii.txt` |
| 官方命令行文档 | 稳定的对外接口契约 | docs.snipaste.com/command-line-options |

复现：

```powershell
dotnet run --project tools/QmExtract -- "<Snipaste>\lang\zh_cn.qm" --out docs/reverse/snipaste-ui-zh.txt
```

> 说明：`.qm` 的容器布局在 Qt5/Qt6 之间有差异，本提取器先按标准 section table 解析，失败则退化为
> “UTF-16BE 游程 + Latin-1 反证”的结构化雕刻，因此不依赖具体 Qt 版本。

## 2. Snipaste 技术画像（2.11.300.0，Store 版）

| 项 | 值 | 含义 |
|---|---|---|
| 框架 | **Qt 6**（Qt6Core/Gui/Widgets/Network/OpenGL/PrintSupport/Svg/Concurrent/Xml） | 说明其跨平台、界面自绘 |
| 主程序 | `Snipaste.exe` 6.4 MB | 单体原生程序 |
| 辅助库 | `hoedown.dll` | Markdown→HTML（用于“复制 HTML”） |
| 网络 | Qt6Network + OpenSSL(libssl/libcrypto) | 更新检查、在线 OCR、在线激活 |
| 本地化 | `lang/*.qm` 40+ 语言 | 文案即功能面 |
| 图像格式 | imageformats: jpeg/webp/tiff/apng + Qt6Svg | 支持粘贴/保存这些格式 |
| 平台 | `platforms/qwindows.dll`, `styles/qwindowsvistastyle.dll` | 原生 Windows 主题 |

## 4. 明确不复刻的部分

- **授权/激活/订阅校验**（`在线激活 Snipaste 2 专业版`、`反激活`、`授权码`）：属于付费产品机制，不移植。
- **在线 OCR（百度/腾讯）**：会把截图外传，违背本项目“本地优先”的定位；保留本地 OCR + 可选 Tesseract。
- **自动更新器 / 腾讯管家等第三方冲突检测**：与功能无关。
- 任何图标、皮肤、语言包、文案原文：全部自行绘制/撰写。

## 5. 版本与许可

- TaskPin 以 MIT 许可开源，与 Snipaste 无任何隶属关系；功能对标属“独立实现（clean-room）”。
- 逆向仅用于理解**行为契约**（菜单结构、参数含义），未复制其实现代码、资源或文案。
