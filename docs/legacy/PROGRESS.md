# 开发进度与路线图

> 更新时间：2026-11-08（第 14 轮）

## 第 14 轮完成

### 1. 卡片/贴图右键菜单改为原生菜单（根治"点了没反应"）
- 根因：`ContextMenuStrip` 是托管控件，挂在 `WS_EX_NOACTIVATE` 窗口上时**能画出来但收不到输入**
- 换成 Win32 `TrackPopupMenuEx`（`Interop/NativeMenu.cs`），走系统模态菜单循环，前台状态无关
- 验证：右键卡片 → 键盘 Down/Enter 选中 → 日志 `card menu (native) picked=True`

### 2. 日历激活
- 日历改由隐藏的「可激活宿主窗口」持有（`MenuHostForm`），并用 `AttachThreadInput` 强夺前台
- 验证：日志出现 `calendar activated`；点击月历「›」成功切到 2026 年 12 月（右侧显示 12月1日）

### 3. 仍待办：界面与 Snipaste 完全对齐
- 需要在真机上抓取 Snipaste 截图作参照，逐项对照工具栏/配色/文字工具，下一轮处理
## 第 13 轮完成（按第二轮反馈修复）

### 1. 工具按钮错位（严重 bug）
- 根因：`SetTool((ToolKind)(i + 1))` —— 枚举从 `Select=0` 开始，`+1` 让整排按钮全体右移一位（点矩形画出圆）
- 修复：`SetTool((ToolKind)i)`，高亮判断同步改回 `== i`
- 验证：点第 2 个图标（矩形）拖拽 → 画出矩形（260×160），图标高亮正确

### 2. 日历层级 / 卡顿
- 日历改为 `TopMost`（与卡片同层），打开时 `AllowSetForegroundWindow` + `SetForegroundWindow`，不再需要先点一下桌面才响应

### 3. 右键菜单卡顿（贴图 / 卡片）
- 加 `AllowSetForegroundWindow(-1)` 后，实测 **贴图菜单 11 ms、卡片菜单 10 ms** 弹出（日志 `pin/card menu shown in … ms`）

### 4. 卡片左上角右键无效
- 根因：卡片是分层窗口，**alpha=0 的像素不接收鼠标**，四周边距/圆角处右键会穿透到桌面
- 修复：画布底色改为 alpha=1，整个卡片矩形都可点击；同时接管 `WM_NCRBUTTONUP` / `WM_CONTEXTMENU`，避免弹出 Windows 系统菜单

### 5. 外观设置改到「设置」里
- 卡片右键不再放外观子菜单；改为 设置 → 卡片 → 卡片背景色 / 卡片文字色
- 不透明度仍在同一页的滑块里调

## 第 11 轮完成（按你的反馈修复）

### 1. 文字标注重做
- 原来点第二次会残留输入框、只能单行、点别处不提交
- 现在：**失焦即提交**、`Enter` 提交、`Shift+Enter` 换行、`Esc` 取消
- **双击已有文字可再次编辑**；清空内容直接删除该标注
- 绘制用 `TextFormatFlags.NoPadding`，文字位置与输入框完全对齐

### 2. 卡片日期 → 日历
- 双击卡片右上角日期打开日历（看每天完成数 / 待办 / 顺延）

### 3. 右键卡顿
- 根因：卡片/贴图是 `WS_EX_NOACTIVATE` 窗口，弹出菜单前临时去掉该样式，但菜单关闭后**没有一定恢复**，卡片变成可激活窗口，开始抢焦点 → 之后点击发涩
- 现在：菜单关闭 + `Show` 返回后都强制恢复样式；并加了一道保护——**只有真的点在卡片范围内的右键才弹菜单**，避免菜单出现在别处
