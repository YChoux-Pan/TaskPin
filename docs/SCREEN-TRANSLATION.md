# 区域截图中的翻译贴图 · TaskPin 0.4.3

按 **F1** 框选画面，在截图工具栏点击 **翻译**（或框选后按 **Ctrl+T**）。它与「识别为任务」并列，直接使用当前选区和标注，不需要第二次截图。

「设置 → 热键 → 翻译当前选区（F1 框选后）」可修改翻译按键；它只在截图编辑器内生效。F1 框选后按 **F3** 固定当前选区和标注，平时按 F3 贴剪贴板。工具栏显示实际生效键；设置会拦截全局备用键与编辑器操作冲突。

结果是原位置的一张**桌面贴图**，不是默认打开的翻译结果弹窗。识别/翻译中显示状态，成功后中文译文原位覆盖；拖动或缩放期间完成翻译，保持当前位置、缩放和方向。完成状态几秒后自动隐藏，右键始终可查看。

独立的截图翻译托盘按钮、Ctrl+Alt+T 热键及专用框选遮罩已移除。翻译保留在 F1 工具栏中；服务配置仍在「设置 → 截图翻译」页，共用「AI」页接口、模型和 Key。

## 贴图操作

- 拖动移动，滚轮以光标下的图像点缩放，反向滚动立即改变方向；Ctrl+滚轮调整透明度，方向键微移；双击、Esc 或 Delete 关闭。
- 右键选择「查看原图 / 显示中文译图」「查看文字对照」「复制译文」「重新翻译」「取消翻译」「翻译设置」或「重新截图」。文字对照仅在主动选择时打开。
- 复用原贴图的边框/阴影、旋转/翻转、穿透、分组、复制和保存，原译切换仍保留方向与缩放。F3 贴剪贴板、Shift+F3 显隐全部贴图。
- 每次翻译生成新贴图，保留前面的结果；同时只运行一个主要识别/翻译任务。新的处理会取消之前未完成的处理，旧贴图保留图像，可右键重试。取消 OCR 后重试从保留的原图重新识别，不会重置拖动位置。
- 窗口关闭、隐藏、分组或截图期间的迟到结果不重新显示贴图。打开设置会取消正在处理的翻译，暂时隐藏翻译贴图，关闭设置后恢复。

## PaddleOCR 本地识别

默认文字识别使用 **PaddleOCR PP-OCRv5** 检测与识别模型，以 RapidOCR 执行封装和 ONNX Runtime CPU 推理。设置 → 截图翻译可选择自定义兼容 PP-OCRv4/v5 mobile/server ONNX 配置；模型路径、家族、类型、SHA256 和 CPU 线程参数见 [配置格式](../TaskPinQt/ocr/README.md#local-model-profiles)。实际模型版本显示在识别结果中。RapidOCR 是模型调用与预后处理组件，实际识别模型为 PaddleOCR 系列；没有调用 Windows.Media.Ocr，也没有云端 OCR。

应用按需启动一个本地识别进程，连续截图复用已加载模型；空闲 60 秒释放，切换模型重新加载。便签和翻译共享队列，取消/关闭后丢弃迟到结果。自定义模型保存先做可取消的后台加载验证，验证中不写设置；取消保留原配置。兼容性由实际引擎验证，未来模型家族需要适配，修改配置标签不会自动获得新引擎能力。

便携包包含独立 Python 运行时、锁定依赖、离线模型、SHA256 与许可证。无需系统 Python、Windows OCR 语言包或 CUDA。运行时不自动下载模型，截图经 stdin 内存传递，不保存截图/识别内容文件。识别输出原图物理坐标、实际识别分数与模型元数据；分数不是校准后的正确概率。

「识别为任务」与翻译共用同一 PaddleOCR 识别适配器。技术符号、下划线、大小写和公式仍应切换原图核对；使用该模型不能保证任意图片无误。

## 翻译设置与数据

在「设置 → AI」配置现有 HTTPS 接口、模型和 Key；截图翻译页选择云端模式并授权文字翻译。便签 AI 归纳开关独立控制。测试连接只发送固定虚构短句，每次绕过缓存；取消设置不保存草稿，保存失败保留草稿并报告原因。

新安装默认仅本地 OCR，不擅自上传识别文字。云端只发送授权文字，不上传截图；取消不能撤回已经发送的数据或费用。Key 沿用原 AI 配置的本机存储，翻译不另存一份。不要公开用户配置、数据库、日志或历史。

翻译动作不自动创建便签、不写截图历史或更新上次区域。普通截图复制/保存/识别为任务保持其原有行为。只在主动保存贴图时导出图像，默认无持久翻译历史。

## 渲染与边界

成功块按 OCR 坐标覆盖局部背景并绘制译文，代码/公式和失败块保留原图。最小字号11px；放不下的长文使用图下编号注释，达到32MP预算时提示查看文字对照。复杂背景采用局部底板，不声称内容感知去字或复刻有道私有算法。

网络保持 HTTPS 校验、手动重定向、单次超时、180秒任务预算、严格 JSON/块ID/占位符校验及一次问题块修复。模型仅在本机做识别。分阶段耗时、模型选择、测试计数与未验证范围见 [0.4.3 专项报告](reports/2026-11-21-ocr-performance-0.4.3.md)。
