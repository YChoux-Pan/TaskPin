# 截图翻译 · TaskPin 0.4.1

按 **Ctrl+Alt+T** 框选文字，截图经过本地 Windows OCR，译文直接绘制到原图中对应文字位置。默认显示译图，可一键切换 **原图** 或 **文字对照**。F1 区域截图保持独立；翻译不更新原截图上次区域、不加入截图历史，也不创建便签任务。

## 配置一次即可使用

1. 打开「设置 → AI」：使用原有的接口、模型和 API Key，已配置的密钥以圆点显示，不需要在翻译中重复填写。便签 AI 开关只控制任务标题归纳。
2. 在新增「截图翻译」页选择云端模式，核对共享的发送地址，允许主动截图后的文字翻译。取消授权、或改变接口地址，会阻止发送截图识别文字。
3. 点击「测试连接 · 仅发送测试短句」，使用当前填写的草稿配置发出真实请求；每次测试均绕过翻译缓存。该测试不发送桌面或便签内容、不保存草稿、不替用户开启截图授权。
4. 点击整个设置窗口的「保存」。取消或关闭不保存草稿。以后按 Ctrl+Alt+T 即可。

旧 0.4.0 的独立翻译密钥不再读取。翻译直接使用现有 AI 模块的本机配置；密钥仍按原 AI 模块方式保存在 settings.json，不新增另一份密钥。请勿公开用户配置、数据库、日志或历史。0.4.0 的模式、超时和同一接口的授权可以继续使用。

托盘「截图翻译设置」、结果窗口「翻译设置」和 AI 页入口都会打开**同一个设置窗口的截图翻译页**，没有嵌套模态弹窗。设置期间隐藏译图，关闭后恢复其可见性和置顶状态；正在处理的请求先取消。

## 结果操作

- **译图**：依据 OCR 块的图像物理坐标遮盖原文字并绘制译文，周边图像保留。浅/深色背景分别选择可读文字色，自动换行与字号适配，最小 11px。
- **原图**：无损切换，原始截图从未被译图覆盖。窗口支持缩放和滚动。
- **文字对照**：原文与译文均可选择、滚动、复制。译文太长时，图下使用完整编号注释，避免截断或盖住相邻代码；达到 3200 万像素渲染预算时明确提示切换文字对照查看全文。
- **保存译图**：PNG 输出使用与画布相同的合成图，成功后复制文件路径；失败保留窗口并提示。置顶、复制译文、取消、翻译/重试、重新截图保持可用。
- **失败处理**：没有成功译文的块保留原图。错误或超时保留识别原文；重试复用 OCR。关闭/取消后，旧结果不能覆盖下一次截图。

## 模式与数据范围

| 模式 | 行为 |
|---|---|
| 云端翻译 | 共用 AI 页的 HTTPS 接口、模型和 Key，仅发送授权的 OCR 文本 |
| 仅本地 OCR | 只识别，不提供离线中文翻译 |
| 离线 Mock | 标记为非真实译文的流程演示，不联网 |

默认新安装不擅自上传截图文字。已有配置按所保存模式运行。截图通过子进程 stdin 进入 Windows OCR 内存流，不创建输入图片/识别内容文件；原图与译文不默认持久化。仅主动保存时导出。取消不能撤回已经发出的文字或费用。

## 技术文字与精度

保留 HALCON 算子/参数/类型/代码/公式、数字（含正负号及科学计数值）、路径和枚举，占位符与块 ID 严格校验，问题块最多再修复一次。只处理纯文本响应，不执行返回 HTML 或命令。HTTPS 证书校验开启，不跟随重定向，单次默认 60 秒，任务预算 180 秒；选区 1600 万像素、文本 32000 字符/128 块、响应 1 MiB、最多 64 块内存缓存。

**保护只能保留 OCR 已识别内容，不能保证识别没有错误。** 本机仅有 zh-Hans-CN OCR，可能混淆下划线、l/I、大小写和技术符号；界面保留原图及实际语言提醒。没有引入有道二进制、私有接口或模型。原图覆盖使用局部背景色估计，复杂照片、纹理与渐变不能等同于内容感知修复；不确定/超长文字可用对照查看。
