# 截图翻译

TaskPin 0.4.0 新增独立的“截图翻译”：按 **Ctrl+Alt+T**，框选当前显示器的文字区域，松开后进行本地 OCR，再在独立窗口显示原文与简体中文译文。托盘也提供“截图翻译”和“截图翻译设置”入口。

原有 **F1 区域截图**、标注、截图保存、贴图、识别为便签任务保留原有含义。翻译截图不加入截图历史，不创建/完成便签任务，不更新原区域截图的“上次区域”。同一时刻只显示一个选区遮罩，避免混淆操作。

## 首次使用

默认是“纯本地 OCR”，无需 API Key，不发网络请求。结果窗口中打开“翻译设置”，可选择：

| 模式 | 说明 |
|---|---|
| 纯本地 OCR | 只识别、显示原文；没有离线中文翻译模型 |
| 离线 Mock | 验证截图、OCR 和界面流程，输出带标记的原文；**不是真实译文** |
| DeepSeek / OpenAI 兼容 | 使用提供 Chat Completions JSON 输出的服务，发送文本进行翻译 |

可点“从现有 TaskPin AI 配置填入”，主动导入接口地址、模型和密钥。翻译设置独立保存，默认不会擅自使用便签 AI 或发送文字。云端模式要求有效 HTTPS 地址、模型、密钥，以及对界面显示的具体发送地址作出授权。修改地址会撤销此前勾选的授权。

新的翻译密钥保存在 **Windows 凭据管理器**，不会写入 translation.json。凭据不可用会明确报错，不退回明文。导入不会自动清除便签 AI 原先保存的密钥；旧便签 AI 的凭据方式属于既有行为，见 README 隐私说明。

## 结果窗口

- 左侧 OCR 原文、右侧中文译文，均可滚动、选择和复制；只有点击复制按钮才改变剪贴板。
- 原图缩略图和“查看原图”用于核对公式、数字、大小写、下划线与参数。
- 支持置顶、重新截图、取消和重试。重试使用已经识别的文本，不重新截图或 OCR。
- 进度显示 OCR、翻译、完成、取消或失败。代码与公式保留原文，未通过校验的块明确标记。
- 窗口关闭或取消后旧请求结果失效，不会覆盖之后的新截图。取消不能撤回已经上传的文字或已经产生的费用。

## 识别与技术文本保护

沿用现有 C++/Qt 架构，截图使用 Qt 当前显示器捕获，OCR 采用独立的 **Windows.Media.Ocr** 适配器。没有引入 Python、RapidOCR/ONNX 或自动下载模型。截图通过管道传给内存流，不保存输入 PNG/识别内容文件；不声称运行时内存可以被完全物理擦除。

OCR 返回行文本、图像局部物理像素位置和实际识别语言。Windows 引擎不提供置信度时记为未知，界面提示核对；不能把空值写成虚构分数。若缺少语言包或超出系统引擎能力会提示失败，可缩小选区重试。

首版按单栏文档恢复段落，保留行 ID。疑似双栏/表格会提示阅读顺序不可靠。代码调用和公式绕过翻译，内联算子、参数、类型、路径、URL、版本与数字通过随机任务占位符保护。占位符/块 ID/数量严格校验，问题块只再尝试一次；仍失败保留原文。术语资源位于 `TaskPinQt/assets/translation/glossary-halcon.json`。

**保护的是 OCR 已识别的文字，并不能修复最初识别错误。** 本机只有 zh-Hans-CN OCR 语言包，虚构样本中下划线及 l/I 有误识别。因此保留原图、语言提示和原文，不声称已达到 HALCON 参数/公式零错误。

## 网络、并发与保存边界

- 截图留在本机，只有授权的 OCR 文本进入用户选择的接口。
- TLS 校验开启，不跟随服务重定向，响应内容不作为命令、HTML 或链接执行。
- 单个主要翻译任务，块按顺序处理；自动修复最多一次。鉴权、限流、网络失败不无限自动重试。
- 单次网络默认 60 秒，任务总预算 180 秒；选区最多 1600 万像素，文本最多 32000 字符 / 128 块，响应最多 1 MiB。
- 仅保留最多 64 块的进程内 LRU 翻译缓存；没有默认开启持久化翻译历史或缓存。
- 日志不记录本模块的截图、OCR 原文、译文、密钥或响应正文。

接口依照 DeepSeek 官方 Chat Completions 文档使用 `messages`、`response_format: json_object`、`finish_reason` 与返回完整性校验。兼容服务必须支持同一协议；不支持时显示错误，不把缺失/截断结果当成成功。真实付费接口未在自动化测试中调用。

## 测试与后续

自动化覆盖反向拖动、100%/125%/150%/200% 坐标、负屏幕原点、原截图/便签隔离、保护片段、缺块/重复块、截断、HTTP 401/429、超时、取消后迟到响应、隐私默认关闭和隔离凭据读写。Windows OCR 探针只使用程序生成的虚构文字，不截取用户桌面。

本机探针观测、实际计数和未验证范围见对应版本报告。Windows 10、所有物理混合 DPI 组合、30–50 张独立 OCR 回归集、正式云端服务语义质量尚未完成验收。

静态译文覆盖、复杂表格恢复、OCR 原文编辑、真正离线翻译模型和可选历史属于下一阶段；首版以清晰的原文/译文对照为交付范围。
