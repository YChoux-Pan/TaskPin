## Independent review and corrections

Task reviews and one whole-branch review examined the editor, history, coordinate mapping, pin/menu behavior, namespace isolation, notes compatibility, packaging, CI, licensing and evidence claims. Findings corrected before this record:

- Save-error text hidden by the toolbar in a constrained full-screen selection.
- Data-directory aliases resolving differently before and after directory creation.
- Unsupported Qt add-on and outdated compiler-package selectors in the hosted installer.
- Settings dialog writing the normal account's autostart value before the host's automation guard; the write now occurs only in the guarded host path.
- Missing visible current pin percentages after wheel adjustment, and an inaccurate line-width history claim.

The final scoped review resolved all original findings with no Critical/Important issue remaining. Its one nonblocking placement observation is documented below.

## Decisions and their limits

1. Automation uses `Qt::Window` for screenshot/pin/card discoverability by the supported desktop tools; ordinary use retains `Qt::Tool`. Event handlers are shared. If this assumption is insufficient, taskbar/focus/window-manager behavior differs and requires normal-mode desktop checks.
2. The Windows-only integration test uses a read-only native registry snapshot outside production `src/platform/` as an independent oracle. It never enters the application binary or writes registry values. If this placement proves inconvenient, the cost is localized test/platform maintenance; it can move to test-only platform support without changing product behavior.
