# 保存路径与 Snipaste 默认快捷键

2026-11-20，0.3.0 后续开发改动，尚未创建新的正式发行标签。

## 行为

- 截图编辑器的保存、另存为和快速保存，只有 PNG 写入成功才将最终文件的完整 Windows 路径写入剪贴板。中文、空格与相对输入路径都转为可用的绝对路径。
- `Ctrl+Shift+S` 保存到设置中的自动保存目录，沿用唯一文件名逻辑，不覆盖同名截图。`Ctrl+S` 继续弹出另存为对话框。
- 保存失败时保留编辑器和原剪贴板；取消保存没有输出。`Enter` 继续复制图片。
- 对应全局默认值为 F1 截图、F3 贴图、Shift+F3 全部贴图显隐。TaskPin 特有功能和其余快捷键保留原默认值。
- 设置文件版本由 2 升至 3。版本低于 3 时，只将 Ctrl+Alt+A / Ctrl+Alt+V / Ctrl+Alt+H 这些旧默认值迁移到新的对应默认值。自定义按键保留；版本 3 的用户重新选择旧按键也不会被重复迁移。
- 保留 Windows 热键冲突的备用键逻辑，以托盘显示的实际注册值为准；两个常驻应用无法同时独占同一全局热键。

本机更新通过正常退出完成，保留私有备份。核验更新后的普通使用实例、程序 SHA-256、数据库内容、截图历史文件哈希、任务数量与非快捷键设置。快照中实际热键注册结果用于确认占用后的备用键，个人数据及日志不上传。

这些回归在 Qt offscreen 平台运行，未把它们描述为完整的真实桌面验收；原生文件对话框的人工取消、第三方应用粘贴兼容性及物理键盘全链路仍属于单独的实机覆盖范围。
