# 截图翻译修复与原图译文设计

用户授权自动实现、实机验证、本机更新、主分支和发行上传，无需重复确认。保持 C++17/Qt6，不迁移技术栈。此次修复以用户明确提出的「共用成熟 AI 配置、统一设置页、原图覆盖」为准。

## 已查证问题

已有 AI 配置的 DeepSeek 合成文本请求 HTTP 200；0.4.0 翻译凭据库中的另一个密钥 HTTP 401。凭据写入本身可成功，旧密码框重新打开为空也易被误认为未保存。翻译设置独立模态 exec、主设置置顶、多个入口组合形成不必要的模态/层级冲突。改为单一非模态设置窗口。

## 交付行为

- 设置新增「截图翻译」页，AI 页仍是唯一接口/模型/Key 编辑入口；翻译默认复用该连接，云端模式与便签标题归纳开关独立。沿用既有文本外发授权，修改接口必须重新勾选；没有已保存授权时不上传截图文字。
- 页面展示共享连接状态、超时、本地/Mock/云端模式、测试连接按钮。测试只发送固定虚构短句，异步、可取消，不保存未提交设置，不显示或记录密钥。保存与取消适用于整个设置窗口。密码字段回显掩码并提示已配置，取消不修改原设置。
- Ctrl+Alt+T 独立框选不变。选区后默认原图译文视图，OCR 块带坐标进入渲染层。译文覆盖在对应文字位置；根据背景取样遮盖文字、选深浅文字色、自动换行/字体适配。代码与公式保留。没有成功译文的块保留原图。不能放下的长段落转到图下完整标号注释，避免裁切与遮盖相邻块。
- 一键「原图」「译图」「对照」，缩放/滚动、复制译文、保存译图、置顶、取消、重试、重截。对照文字保留可复制全文；原图不被破坏。保存失败保留窗口并显示错误。
- 所有设置入口聚焦同一窗口的翻译页，取消当前云端任务，移除嵌套模态对话框。反复打开不会阻塞 UI；关闭清理请求，旧结果不影响后续任务。
- 保持单任务、取消、限额、HTTPS/手动重定向、严格 JSON/ID/占位符保护。仅文字发到明确授权接口。新版本 0.4.1。

## 验证

先复现关键失败再修复：共享连接而非旧翻译密钥；原图/译图像素及块坐标；长译文不截断、不覆盖代码；反复打开设置只有一个非模态窗口；保存/取消及Key重新加载；真实生产 Client 固定样本 API 请求；真实 Windows OCR→翻译→原图渲染。全部既有四套测试/自检、便携包独立运行、发布字节/任务历史保护。报告区分本机样本与全面OCR准确率验收，不声称复刻有道专有模型或完美去字。
